# 与 CoMath 的一致性边界

依据公开设计比较，而不是对未取得的 CoMath 实现进行行为验证。来源与范围见 SOURCES.md / SOURCE-COVERAGE.json。

| 能力 | 本包实际实现 | 一致性结论 |
|---|---|---|
| 共享研究状态与会话恢复 | 本地 SQLite、内容对象、检查点、会话绑定 | 工作流相近；不是同一种存储/服务实现 |
| 命题锁、任务依赖、阶段推进 | 当前 spec hash、任务 DAG、六道累计门禁 | 概念一致；不是 CoMath 原生 schema/API 兼容 |
| 多角色与反例审查 | 9 个共源提示词；真实宿主 subagent 或注明顺序检查 | 研究规范对齐；控制器不启动模型 |
| 过期结果和协作竞争 | 原子领取、租约、心跳、预算、过期拒收 | 对合规客户端实现；无 OS 身份隔离 |
| 证据来源与变更失效 | 来源/对象/任务产物哈希、撤回、问题绑定、快照审阅 | 已实现保守失效；语义依赖仍需人工登记 |
| Codex 生命周期 | 项目级原生 command hooks 和 agent TOML 安装器 | 按所读官方文档实现；缺少真实 Codex 端到端验收 |
| 形式验证 | 受限 Lean 项目适配器、本地类型/公理回放、产物绑定 | 有实现与 mock 测试；未在本环境运行真实 Lean |
| `comathd` 单一可信写入边界 | 本包由合作式 coordinator/CLI 写 SQLite | **不等价**；不抵抗同 OS 用户直接写状态 |
| host-only 人工授权/盲审隔离 | 本地 human-ack 与过滤后的盲审 packet | **不等价**；都不是身份或访问控制证明 |
| 全依赖 hermetic replay | 明确未保证；受审 Lake 脚本可能用缓存 | **不等价**；不得借用 CoMath 证书名称 |
| 实际研究效率与费用 | 仅合成 hook 进程开销测量；尝试次数预算 | **未证明等价**；没有同任务模型对照实验 |
| 旧 v8 状态/插件兼容 | 保留旧文件；新运行时独立 | **未迁移/未完整回归** |

## 建议保留两种部署档位

**便携档（本包）**：不安装 Pi，也不要求常驻服务；同一研究者的受信任本地工作区。价值是可恢复、可审阅、不会把形式与非形式证据混为一谈。其协议应明确标注 local/cooperative。

**同内核档（后续工作）**：不用 Pi UI，但通过已公开描述的 HTTP/in-process 接口使用原 `comathd`。既然 CoMath 将 Pi 设计为薄宿主，这才是最大程度复用原权威边界、避免两套证明状态机分叉的路线。先取得真实服务代码、schema、鉴权和 host-only 合约，再写薄客户端与契约测试。本包没有猜测这些接口的身份语义，也没有实现一个未经测试的“等价”代理。

两档可以共享角色协议和用户概念，但不能共用未标注来源/信任等级的最终证书。跨档导入先降为候选材料，再由目标档位重新验证。
