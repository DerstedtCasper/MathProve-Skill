# Stage-Parallel Ensemble v7

Parallelize inside stages. Each branch writes a comparable manifest with stage, branch_id, claim, dependencies, artifact paths, tool status, hard vetoes, risks covered, and maintainability notes.

Scoring: Lean/SymPy certificate 40; closed dependency graph 20; refuter coverage 15; maintainability 10; evidence manifest 10; restartability/cost 5. Any hard veto forces rejection.
