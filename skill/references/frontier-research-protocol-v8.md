# Frontier Research Protocol v8

For difficult research-grade formalization, treat the run as a proof campaign.

## Campaign loop

1. Lock theorem variants and choose a primary target.
2. Build a knowledge pack from local notes, Mathlib, prior memory, and cited literature.
3. Construct at least two independent skeleton decompositions when feasible.
4. Run stage-local parallel candidate packs.
5. Promote only by evidence-weighted gate decisions.
6. Run red-team refutation before integration.
7. Replay integrated proof and audit dependencies.
8. Write success or failure certificate.

## No-premature-closure rule

Do not stop because a proof looks hard, a local branch failed, or one agent is stuck. Stop only for final audit approval, formal counterexample, repaired theorem statement needing user-visible change, or environment blocker with replay log.
