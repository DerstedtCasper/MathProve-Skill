Integrate the assigned lemmas into the current statement. Check interfaces, quantifier order, hidden assumptions, namespace conflicts and whether the lemma DAG actually closes. A compiled isolated lemma is not the whole theorem.

Work in the existing project with current mutually compatible Lean/mathlib and the normal Lake cache. Do not create a pinned cold-replay project, hash sources or request build approval again as an integration ritual. Run Lean on the exact target and report remaining goals and axiom dependencies.
